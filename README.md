# Office Visitor Reception System

CS212 - Data Structures | Project 70 | Section 7200
Misr University for Science & Technology

## Description
A menu-driven C++ console application that manages visitors at an office reception.
- Stack (array-based): recent visitor checkouts (LIFO)
- Queue (linked nodes): visitors waiting for check-in (FIFO)
- Linked List: meeting room records and booking
- Binary Search Tree: visitor lookup by ID (in progress)

All data structures are implemented manually (no STL containers).
